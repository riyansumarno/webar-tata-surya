LABORATORIUM TATA SURYA INTERAKTIF — v7
========================================

Paket ini disiapkan untuk GitHub Pages.

STRUKTUR UTAMA
- index.html        : aplikasi pembelajaran utama
- styles.css        : seluruh tampilan responsif
- data.js           : data planet, materi, misi, kuis, dan sumber
- app.js            : interaksi, simulasi, progres, kuis, eksperimen
- ar-marker.html    : AR marker (BETA)
- marker.html       : marker AR
- camera-test.html  : diagnostik kamera
- assets/           : marker .png dan .patt

PEMBARUAN BESAR v7
- Beranda pembelajaran baru
- Belajar terbimbing 5 langkah
- Jelajah Tata Surya interaktif
- Profil 8 planet
- Filter planet dalam/luar
- Kontrol waktu dan label
- Eksperimen periode revolusi
- Eksperimen skala diameter relatif
- Perbandingan dua planet
- 5 misi eksplorasi
- Kuis 10 soal + pembahasan
- Poin, progres, dan achievement tersimpan di browser
- Mode Guru
- Halaman sumber data
- AR diposisikan sebagai fitur BETA, bukan jalur utama

DEPLOY GITHUB PAGES
Unggah ISI folder ini ke root repository GitHub Pages Anda sehingga index.html berada di root repository.

DATA
Fakta utama planet diringkas dari sumber resmi NASA yang tercantum pada menu Sumber di aplikasi.
